# AA-1153 part 1: hotel contracts through DMCs (Jira PR-30)

Scope of part 1 (root `docs/audits/2026-11-19-S285-session/advisory-r2-plan.md` slice L10): T8 property master, T9
board basis, B7 net prices, T10 DMC rate-sheet importer with business checks and a diff before approval, contract
seasons and per-night prices, external codes, T11 hotel confirmation number and the facts re-confirmation date. Part 2:
allotment / release days on quotes (B8) and the Excel two-way round trip (facts and room-type sheets, export).

Migration `bk-069` (contract class) ships first in its own PR; the code PR raises readiness to `bk-069`.

## Decisions

- **`hotels.supplier_id` stays** (NOT NULL, "the supplier that first listed the hotel"). The DMCs that sell a hotel are
  `booking.hotel_supplier_links` rows (backfilled one per hotel; an AFTER INSERT trigger keeps it for every new hotel).
  Making `supplier_id` nullable and dropping the old unique key is a later contract step, once nothing reads it.
  Every check "is this room type the supplier's?" now asks for an active link: the two DB guards (rates,
  restrictions), `rates.create_rate`, `restrictions._component`, the supplier-booking supply check and the importer.
- **Which DMC's price a quote takes** (`app.supply.rates`, one SQL for every caller): per supplier, the same choice as
  before (newest validity, pax band, lowest net), with the asked board first; across suppliers the asked board first,
  then the hotel's preferred DMC (`is_preferred`), then the lowest net. A service has one supplier, so services price
  exactly as before.
- **Board basis (T9)**: a lookup asks a board or none. None = the default board BB: an exact BB rate first, then a rate
  with no board, then any other board (old data keeps pricing). An explicit board takes that board or a rate with no
  board, never another board (a BB rate never silently wins over an asked HB). The board comes from the quote line
  (`meal_plan`, agency or staff desk), else the tour night (`trip_plan_components.meal_plan`), else BB.
- **Double dinner warning**: a tour line whose night is HB / FB / AI and whose same day holds a `meal` service, or an
  `rt:` line on HB / FB / AI with a `meal` service line of the same quote on one of its nights, gets
  `price_note.board.warnings` (`double_dinner` with the dates). A warning only; the price is unchanged.
- **The booking goes to the DMC of the price used**: a quote part stores the supplier of its rate's contract (was the
  hotel's supplier); a version item's supplier is the contract supplier of its first cost row's rate, else of the B2B
  quote line's first rate, else the hotel's / service's.
- **B7** was already in bk-060 (`published_amount` + `commission_pct`, net derived half-up). Part 1 adds nothing but
  the end-to-end proof (a second DMC's "70 USD, 20 %" row imports as 56.00 with both source numbers).
- **Hotel child prices** are per (contract, hotel), age band, basis sharing / extra bed, optional board, net per night.
  A room line charges them only for the children the room mix cannot hold (rooms given explicitly; the default mix
  already rooms every traveller): the oldest children first (conservative), each by the band of its age
  (`child_ages`), an unknown age by the band reaching the oldest age. No matching policy = no extra (as before) and
  `price_note.child_room` says so.
- **Seasons**: `supplier_contract_seasons` (name + range; a season may have several ranges). A rate keeps its own dates
  and season label; per-night pricing reads the rate dates. The importer's optional `Seasons` sheet expands a rate row
  that names a season and gives no dates into one rate per range.
- **Business checks** (`app.supply.rate_checks`, pure): `board_order` (RO <= BB <= HB <= FB <= AI for the same room,
  dates, band), `season_gap` (contract days no season covers), `season_overlap` (two seasons on one day: an error),
  `price_jump` (a net above the previous contract's same rate by the policy `rate_sheet_jump_warn_pct`). Errors block
  the import; warnings are listed at the dry run, stored with the import and must be acknowledged by the second person
  who publishes a draft that came from an import (`acknowledge_checks`, 409 `checks_unacknowledged` otherwise).
- **Diff before approval** = the draft's rates against the supplier's previous published contract, keyed by target,
  board, pax type, pax band and season (or the rate dates): added / changed (old and new net, %) / removed. Live on
  `GET /booking/contracts/{id}/review`, stored at import time in `rate_sheet_imports.diff`.
- **Duplicate hotels** (`app.supply.hotel_master`): normalised name (lower case, accents and punctuation removed,
  common words such as hotel / resort / spa dropped), `difflib` ratio, haversine distance. Block: similarity >=
  `hotel_match_block_pct` and (closer than `hotel_match_block_m`, or no coordinates on one side and the same place).
  Warn: similarity >= `hotel_match_warn_pct`, or the same place and closer than `hotel_match_warn_m`: a create or a
  name / place / position change needs `not_duplicate_reason` (10..300 characters, audited). Thresholds are pricing
  policy parameters (section hotels), never literals.
- **Re-confirmation**: `facts_confirmed_on` + the policy `hotel_facts_reconfirm_days` = `facts_reconfirm_due`; the hotel
  list filters `reconfirm=due`. A reminder job is not part 1 (the contract expiry job of AA-1151 is the place to add
  it).

## Changed

- The rate-sheet importer matches hotels linked to the supplier by the DMC's code first, then the AA code; room types
  by name, then by alias (the supplier's alias first, then an any-DMC alias).
- `rate_in_force` (one lookup) now runs the batched query and reads the row by id: one rate choice everywhere.
- A version item's room default net is priced night by night (one cost row per run of nights at one rate), the first
  night choosing the DMC and the next nights staying with it.

## Tradeoffs

- No `pg_trgm`: `difflib` over the hotels of the same place / country / bounding box is enough at today's size
  (hundreds of hotels) and needs no extension migration.
- Child prices only for children beyond the room mix: a triple room for two adults and a child is the triple rate,
  as DMC sheets price it.
- Warnings never block the import itself (DMC promotions are real); they block an unacknowledged publish.
