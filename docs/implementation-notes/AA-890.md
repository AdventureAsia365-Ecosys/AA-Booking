# AA-890 / AA-888 — PR template, PR-title check and ADR index (AA-Booking)

## Decisions

- `.github/pull_request_template.md`: What / Why (`Refs AA-xxx`), Risk and rollback, Cost, Docs checklist and
  Verification with this repo's gates (CI job names, `bk-NNN` copy in AA-CIS-Infra `db/migrations/booking/`
  applied by DB Migrate first, staff-admin preview, `/booking/health` + `/booking/health/ready` after deploy).
- `.github/workflows/pr-title.yml` (AA-890, S243 plan N3/I4): `amannn/action-semantic-pull-request` v6.1.1 pinned
  by commit SHA, types `feat|fix|chore|refactor|docs|ci|test|perf`, optional scope. Two extra rules from the
  commit format: no `[AA-123]` in the title (`subjectPattern`), and no Linear closing keyword followed by an issue
  key in the body (small shell step). Squash merges use the PR title as the commit subject, so the title is what
  lands on `main`.
- Trigger `pull_request` (not `pull_request_target`): no checkout, read-only token, safe for fork PRs.
- The token is passed as `${{ github.token }}`, the same form `ci.yml` already uses for the vendored-copies job.
  No repository secret or variable to set.
- `docs/adr/README.md` indexes ADR 0001 (AA-888, catalog ARCH-05).
- ADR 0001 said "Proposed; becomes Accepted with root ADR 0004". Root ADR 0004 was accepted on 14/10/2026, so the
  Status line now says Accepted, and keeps a note of the old wording.

## Changed

- No application code or existing workflow changed.

## Tradeoffs

- The keyword check reads the PR body from the event payload. `edited` and `synchronize` events carry the
  current body, so an edit re-runs the check with the new text.
- "This fixes the AA-12 bug" is not flagged: Linear only reacts to a keyword directly before the key, and the
  regex mirrors that to avoid false failures.

## Should know

- The check is not required yet. Making "PR title" a required status check is a branch-protection change for the
  main session, together with squash-only and `delete_branch_on_merge` (AA-890 settings list).
- actionlint 1.7.12: clean. Regexes tested locally: the title pattern rejects `add [AA-890] template`, the body
  check flags `Fixes AA-12`, `closes: AA-9`, `Resolved AA-3` and passes `Refs AA-12`.
