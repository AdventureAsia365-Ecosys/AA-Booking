# AA-1134 — Docs-audit code follow-ups (AA-Booking part, slice B)

Lane l5-docs-audit-fixes, S285. The S283 docs audit (root `docs/audits/2026-11-17-S283-docs-audit/README.md`
section 4.1) found places where the docs are right and the code is wrong. This PR holds the Booking items 2, 11, 12 and
13, plus the re-sync of the vendored docs tools (item 5, root `tools/docs/README.md`).

## Decisions

- **`bk_inquiry_pull` leaves `DEPLOY_GATE_EXEMPT` (item 2).** The exemption existed because the recurring singleton was
  always queued. Since AA-1046 the kind has no handler and no schedule, the worker cancels a leftover row
  (`app.b2c.RETIRED_KINDS`), and since AA-993 G5 a queued row of a kind outside `DEPLOY_BLOCKING_KINDS` is information
  only. So nothing can hold a deploy back; the gate's `exempt_kinds` answer becomes `["bk_noop_sleep"]` (Deploy Dev reads
  only `safe_to_deploy`). The unit test now asserts that no retired kind is exempt and that the exempt kinds are the
  test-only ones.
- **Dev port 3001 (item 11).** `npm run dev` and `npm start` move from 3100 to 3001: the port the booking-staff Cognito
  client registers for local sign-in (`lib/cognito.ts` `DEV_ORIGIN`) and the container port (Dockerfile `PORT`). Changing
  the code, not the Infra callback, keeps one port everywhere and needs no Terraform change. Playwright starts its own
  server on 3199, so the tests are not affected. New `lib/devPort.test.mjs` pins the three to one value.
- **API contract public paths (item 12).** `customer/` leaves the `PUBLIC_PATHS` regex of `api-contract.yml`: the
  TripPlanner customer API is retired (AA-1046) and no `/booking/customer` route exists in the OpenAPI document. A new
  unit test reads the workflow and checks that its regex equals the one `test_openapi_export.py` uses.
- **Trip cases copy (item 13).** The "Inquiries" tab itself was already removed (the Booking UI fixes issue); the page
  description and the empty-state line still spoke of TripPlanner inquiries and staff-made cases. Both now describe
  partner bookings from the B2B API.
