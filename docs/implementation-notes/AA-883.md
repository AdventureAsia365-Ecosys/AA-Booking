# AA-883 — Booking side: link back to the CIS console

Part of the S241 admin console work (design `AA-Ecosys/docs/audits/2026-10-17-S241-admin-console/README.md`
§4, §6.3; Nghiệp Q1: one console, every app links across). The CIS side (Platform / CIS Content nav,
read-only Staff directory, Apps links to Booking admin) is AA-CIS-App branch `feat/aa-883-console-nav-staff`.

## Decisions
- A visible "CIS console ↗" link in the staff Topbar, left of the theme switch, built from the existing
  `CIS_ADMIN_URL` (`lib/config.ts`; no new env var). The account menu keeps its "Open CIS admin" row.
- New tab, no token and no return URL in the link (design §6.3).
- Below 768 px only the icon shows (`.aa-topbar-cis-label` joins the existing hide list in `ui/shell.css`),
  so the 390 px topbar keeps fitting.

## Changed
- `frontend/ui/Topbar.tsx`, `frontend/ui/shell.css`.

## Tradeoffs
- Not done here: `ManagedInCisLink` on `app/(staff)/staff/[cisUserId]` pointing at
  `/admin/platform/staff/{cisUserId}` (design puts it in GĐ5). The CIS deep link route exists once the
  CIS branch deploys, so it can be a one-line follow-up.

## Should know
- Verified locally: `tsc --noEmit` and `eslint --max-warnings 0` on `ui/Topbar.tsx` clean. Not checked in
  a browser or on a Vercel preview.
