# AA-1035 — R2 staff roles: Booking finance

Root ADR 0019 d3 / d9 (S265): "Booking reads the role from the Cognito group booking-finance in cognito:groups, backed
by the CIS grant in shared.staff_app_grant (role = 'finance'), like its other roles, and gates the invoice and payment
routes with it. The finance role is not read from the CIS → Booking bridge token." Other halves: CIS 362-364 + the
tenant-scope code (AA-CIS-App), the WORKFORCE groups (AA-CIS-Infra identity.tf).

## Decisions
- `finance` joins `STAFF_ROLES` and `BOOKING_GROUP_ROLES` (last, matching identity.tf precedence 75 after
  content_creator 70), so a person in both booking-sales and booking-finance signs in as sales.
- Permissions: `billing.read` and `billing.write` only (issue / send invoices, record payments). `payment.verify`
  stays admin (design D6 maker-checker; a later decision may give it to finance, still never on a payment they
  recorded). No trip case, customer, pricing, supply, supplier bill or payout permission: the matrix says finance
  works invoices and payments, nothing else.
- `CIS_GROUP_ROLES` (the informational `cis_role` column) lists the six R2 CIS groups; `cis-reviewer` reads as
  `content` (the CIS alias).
- The bridge stays unable to mint finance: `ROLE_FROM_CIS` is unchanged, so a bridge token with `cis_role = finance`
  is 403 `unknown_cis_role` (and CIS refuses bridge tokens for its R2 roles anyway: `NO_BOOKING_ROLES`).

## Changed
- bk-038 (contract, migration-only PR first): `staff_users_role_chk` gains `finance`; readiness raised to bk-038 in
  the code PR.
- Frontend `lib/rbac.ts`: the role, its label, `/billing` and `/billing/*` for finance; the Staff page role help.

## Tradeoffs
- Finance sees the Billing pages only. The invoice screens link to trip cases, which finance cannot open (403 /
  "no access" page); acceptable for the pilot, revisit with the R8 Booking-in-admin move.

## Should know
- Order: Infra apply (group booking-finance) → bk-038 applied → this code deployed → the CIS Staff page grants
  Booking role Finance (CIS 363 must be applied too).
