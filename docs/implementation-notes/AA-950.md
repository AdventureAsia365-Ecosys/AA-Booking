# AA-950 — B2B quote leaves out the live hold of its own proposal version

Lane S252 aa950 (CRM-21b client proposal, fix round 3), agent Claude Code. The CRM side lives in AA-Partner
(`docs/implementation-notes/AA-950.md` there).

## Decisions

- **The quote of a proposal version does not count that version's own live hold.** The CRM (AA-Partner CRM-21b)
  quotes a version's whole AA choice again when the client changes one AA pick, and releases the old hold set only
  after a clean quote (so a genuine sell-out keeps the old hold). `departures.availability()` counted every live hold,
  including that version's own: a client holding the last seats of a departure who changed another pick got
  `sold_out` for seats they hold, and the CRM then marked the option sold out for good. Now `create_quote` reads the
  live `active` hold of the same `(partner, proposal_ref, proposal_version)` (`OWN_HOLD_SQL`) and passes it to
  `departures.availability(exclude_hold=)`, which `usage()` already supported (confirm's own re-count).
- **Only the same version, only `active` and not past expiry.** Another proposal, or another version of the same
  proposal, still sees the seats as taken (a version has one set; versions do not share one). A `confirmed` set is
  sold, never left out (a new hold of that version is refused anyway).
- **The hold is unchanged**: `POST /holds` still locks the departures and counts every hold, and still refuses
  another quote while the version's set stands (422 `invalid`), so the caller must release first; nothing can
  oversell.

## Changed

- `backend/app/b2b/quotes.py`: `OWN_HOLD_SQL`, `create_quote` passes `exclude_hold`; module docstring.
- `backend/app/b2b/departures.py`: `availability(..., exclude_hold=None)`.
- `backend/tests/integration/test_bk020_b2b.py`: `test_a_quote_leaves_out_the_live_hold_of_its_own_proposal_version`.
- `CONTEXT.md`: the line availability paragraph.

## Tradeoffs

- **A Booking change instead of a CRM-only retry** (release, then quote again on `sold_out`): the CRM-only way gives
  up the kept hold on a genuine sell-out and costs an extra release and quote per sold-out answer; this is one
  indexed query per quote. The quote's `price_hash` is unchanged in shape (availability is hashed as before).
