# AA-1152 — bk-070 add-on title on booking.v_place_addons

## Decisions

- bk-070 replaces the bk-068 view with `CREATE OR REPLACE VIEW` and one column appended (`title`); bk-068 is applied on
  Dev and stays untouched.
- The Integration Tests replay every file twice; `CREATE OR REPLACE VIEW` in bk-068 cannot drop the later `title`
  column ("cannot drop columns from view"). Following the bk-062 precedent (`run_062_keeping_later_caps`), the
  integration conftest wraps re-runs of bk-068: `run_068_dropping_later_view` drops the view first when a column from
  `LATER_068_VIEW_COLUMNS` is there; bk-068 recreates it with its grants and comments, bk-070 appends `title` again
  later in the same pass. DB Migrate never re-runs a registered file, so nothing changes on Dev.

## Changed

- `backend/tests/integration/test_bk018_pii_tags.py`: `v_place_addons.title` allowlisted (AA's service name, a contract
  view of `services.title`, which is allowlisted already). The AA-CIS-Infra `PII_ALLOWLIST` mirror needs the same row.

## Tradeoffs

- Dropping the view in bk-070 itself (DROP + CREATE) would also be re-runnable, but loses column comments and still
  would not let bk-068 replay over the newer view; the replay helper is the narrower change.

## Should know

- A later file that appends another column to `booking.v_place_addons` adds it to `LATER_068_VIEW_COLUMNS`.
