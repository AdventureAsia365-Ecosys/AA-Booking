# AA-820 — AI boundary for high-risk advice in Booking CONTEXT (scope point 4)

Linear AA-820 (Tenant Terms clause for the Anthropic Usage Policy effective 12/11/2026). Scope point 4 asks Booking to
record that it gives no AI advice on insurance, financing, claims or visas without a qualified person's review and an
AI disclosure. The rule has been in `CONTEXT.md` ("AI boundary for high-risk advice (AA-820)") since S236; this note
covers the S273 touch-up.

## Decisions

- **Point at the adopted Schedule, not the old draft section.** The section named root
  `docs/legal/tenant-terms-ai-clause-draft.md` §5 as its wording source. That §5 no longer exists: the v0.2 draft
  became the tenant AI Schedule v1.0 (root `docs/legal/tenant-ai-schedule.md`, approved by the tech lead under root
  ADR 0019 b20), and since 2026-11-09 (root #647) the old file name holds only the short main-terms clause v0.3,
  whose item .2 refers back to Schedule clause .3. The agency-side form of the same rule is clause .3(8) of the
  Schedule, so the section names it.
- **Rule text unchanged.** The boundary (insurance choice, underwriting or claims; financing or instalments; refunds
  or claims decisions; visas and immigration; staff review with authority to change; AI disclosure; AI chat disclosed
  at the start of each session) already matches clause .3(8) and the policy's high-risk requirements. Only the source
  sentence changed.

## Changed

- `CONTEXT.md`, section "AI boundary for high-risk advice (AA-820)": the source sentence.

## Tradeoffs

- Copying clause .3(8) word for word into Booking would drift when counsel rewrites it (v1.1); the pointer plus "a
  rewrite there is mirrored here" keeps one source.
